Items here are **not committed**. Each needs a business case, discovery and a PRD section before it is scheduled.

## 1. Intelligence

| Idea | Value | Prerequisites |
|---|---|---|
| Delay prediction (ML on progress velocity, weather, findings) | Earlier intervention | ≥ 12 months of multi-project history |
| Risk scoring per project/site | Portfolio prioritization | Inspections + progress data at scale |
| Automatic as-built vs. BIM deviation detection | Quality assurance | BIM integration, accurate co-registration |
| Earthwork/quantity tracking vs. bill of quantities (5D) | Cost control | Survey volumes, cost data integration |
| Safety analytics (PPE compliance trends, exclusion-zone breaches from imagery) | Safety culture | Privacy review (PRIV-008), customer policies |
| Natural-language report authoring ("draft the monthly report for Tower B") | Productivity | AI-008 maturity |
| Thermal and multispectral analysis (roof leaks, solar panel defects) | New verticals | Payload support, specialized models |

## 2. Operations & Drones

| Idea | Notes |
|---|---|
| Drone-in-a-box automation (scheduled docked flights) | Provider dock APIs, regulatory BVLOS approvals |
| UTM/U-space and LAANC integration for airspace authorization | Jurisdiction-specific |

| Battery lifecycle management | Provider data |
| Multi-drone coordinated missions | Safety case required |
| Remote ID monitoring | Hardware receivers |

## 3. Platform & Ecosystem

| Idea | Notes |
|---|---|
| Native iOS/Android apps with full offline mode | Field inspections without connectivity |
| Public API marketplace and partner apps | API maturity |
| Workflow builder / rules engine ("when a critical finding is created, create a Procore issue and notify X") | Enterprise automation (Phase 4) |
| On-premise / sovereign cloud deployment | Government and defense customers |
| White-label for drone service providers | Multi-client service companies |
| Client portal with custom domains | Owners and lenders |
| Data marketplace (anonymized benchmarks) | Requires explicit opt-in and legal review |

## 4. Visualization

| Idea | Notes |
|---|---|
| Gaussian-splat / NeRF scene support | Photoreal twins with lower capture cost |
| VR/AR site walkthroughs (WebXR) | Stakeholder engagement |
| 4D construction sequencing playback | BIM + schedule integration |
| Split-screen time-lapse video generation from captures | Marketing and client updates |

## 5. Compliance & Security

SOC 2 Type II (Phase 3 target), ISO 27001 certification, FedRAMP/IRAP-style programs (if public sector), customer-managed keys (BYOK/HYOK), private connectivity (PrivateLink) for Enterprise.
