## 2. Clone & Install

```bash
git clone git@github.com:<org>/aerosight.git
```

```bash
cd aerosight && corepack enable && pnpm install
```

```bash
cp .env.example .env.local
```

The defaults in `.env.example` work with the local Docker services. Secrets are placeholders. Use the dev JWT key generated by the setup script:

```bash
pnpm setup:dev
```

`setup:dev` generates a local ES256 key pair, creates MinIO buckets, writes a `.env.local` with generated values, and installs git hooks (lint-staged, commitlint).

## 3. Start Local Infrastructure

```bash
docker compose -f infra/docker/docker-compose.dev.yml up -d
```

| titiler | `ghcr.io/developmentseed/titiler` | 8000 | Raster tiles |
| mediamtx (optional, `--profile video`) | `bluenviron/mediamtx` | 8554 / 8889 | Live video experiments |

## 4. Database

```bash
pnpm db:migrate
```

```bash
pnpm db:seed
```

Seeds create:
- The permission catalog, system roles, plans, system report templates.
- Demo orgs **Atlas Construction** and **Borealis Infra** (identical structure for tenant tests), with one user per role. Passwords for seeded local users come from `db/seeds/dev-users.json` (local-only fixtures) — never reuse them anywhere else.
- Sample projects/sites around Dubai Marina and Munich, simulator drones, missions in each state, a small GeoTIFF, sample images and a short video.

Reset everything:

```bash
pnpm db:reset
```

## 5. Run the Apps

```bash
pnpm dev
```

Turborepo starts in parallel:

| App | URL |
|---|---|
| web | http://localhost:3000 |
| admin | http://localhost:3100 |
| api | http://localhost:4000/api/v1 (OpenAPI UI at `/api/docs` in local only) |
| realtime | ws://localhost:4100/v1 |
| drone-integration (simulator) | http://localhost:4200 (health) |
| workers | (no port; logs in terminal) |
| ai (when `AI_ENABLED=true`) | http://localhost:8001 |

Run a subset:

```bash
pnpm dev --filter=web --filter=api --filter=workers
```

Start the AI service separately:

```bash
cd services/ai && uv sync && uv run fastapi dev app/main.py --port 8001
```

## 6. Try the Core Flows Locally

1. Open http://localhost:3000 and sign in as the seeded Atlas PM.
2. Open **Missions**, pick a `ready` simulator mission, complete the checklist and **Start**. Open **Live Operations** to watch simulated telemetry (striped `Simulated` banner).
3. Upload images from `fixtures/media/` in **Media**. Watch scanning → processing in the job tray.
4. Generate a progress report in **Reports**. Emails appear in Mailpit at http://localhost:8025.

## 8. Working Conventions

- **Branches:** `feat/<area>-<short>`, `fix/…`, `chore/…`. Conventional Commits.
- **New tenant table?** Include `organization_id`, the RLS policy and composite FKs. The schema linter will fail otherwise.
- **New endpoint?** Add `@RequirePermission`, zod DTOs, an audit decorator for mutations, tests (happy, authz-negative, cross-tenant), and update the [API spec](../06-API/API-Specification.md).
- **New permission?** Edit `packages/permissions/catalog.ts` and [RBAC.md](../07-Security/RBAC.md). Run `pnpm permissions:check`.
- **New env var?** `packages/config/env.ts` + `.env.example` + [Environment Configuration](../12-DevOps/Environment-Configuration.md).
- **Capability status changed?** Update [MVP §4](../13-Product/MVP.md#4-implementation-status-register).
- Never commit secrets. gitleaks runs in pre-commit and CI.

## 9. Troubleshooting

| Problem | Fix |
|---|---|
| `ECONNREFUSED 5432` | `docker compose … ps` — is postgres healthy? Check the port isn't used by a local Postgres. |
| RLS returns no rows in a script | Scripts must use `db.withTenant(orgId, fn)`. Raw `psql` as `app_user` needs `SELECT set_config('app.current_org_id', '<uuid>', false);` |
| Upload stuck in "scanning" | ClamAV takes ~1–2 min to load signatures on first start. Check `docker logs clamav`. |
| Map is blank | Set the `NEXT_PUBLIC_MAP_*` URLs. Local default uses the OSM raster fallback (respect the usage policy; don't load-test against it). |
| Cesium errors on Apple Silicon in Docker | Run web natively (`pnpm dev --filter=web`), not in a container. |
| Testcontainers fail on Colima | `export TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock` and set `DOCKER_HOST` to the Colima socket. |
